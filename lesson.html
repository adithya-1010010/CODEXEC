Forms Basics
Instructions
// Objective
Build a contact form using semantic HTML. Your form needs to collect a user's name, email address, and a message.
// Requirements
  • Wrap everything in a <form> element
  • Add a <label> for each field
  • Include an <input type="text"> for name
  • Include an <input type="email"> for email
  • Add a <textarea> for the message
  • Include a <button type="submit">
// Concepts
Forms collect user data. Each <input> should have a name attribute. Labels improve accessibility by linking to inputs via the for/id pair.
// Hint
Link a label to an input by matching for="myId" on the label with id="myId" on the input. Clicking the label will focus the input.
// HTML Forms
The <form> element is a container for input controls. It has two key attributes: action (where to send data) and method (GET or POST).
// Input Types
HTML5 introduced many input types: text, email, password, number, date, checkbox, radio, and more. Each type provides built-in validation.
// Labels & Accessibility
Always pair inputs with <label> elements. Use for="id" to associate them. This improves accessibility and usability — clicking the label focuses the input.
